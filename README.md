## Featured Projects

### 🤖 [Ollama LangChain RAG Assistant](https://github.com/vignesh059/ollama-langchain-rag-assistant)
**Python · Flask · Ollama · LangChain · FAISS · Hugging Face · SQLite**

A privacy-focused AI assistant that runs local language models and answers questions using uploaded documents.

- Built a PDF ingestion pipeline with text extraction, chunking, embeddings, and FAISS similarity search.
- Implemented strict document-grounded responses to reduce unsupported answers.
- Added LangChain tools for PDF Q&A, Wikipedia lookup, and attendance calculations.
- Added JWT authentication, role-based admin access, conversation memory, and a web interface.

**Why it stands out:** demonstrates practical RAG architecture, local AI inference, tool orchestration, and privacy-aware product design.

### 🎓 [DoubtSolver](https://github.com/vignesh059/DoubtSolver)
**JavaScript · Express.js · MongoDB · Gemini API · Tailwind CSS**

An AI-powered Q&A platform for students and educators to ask questions, receive generated explanations, and collaborate through community answers.

- Integrated Google Gemini for automated, context-aware answers.
- Implemented JWT authentication, bcrypt password hashing, profiles, and protected routes.
- Added Markdown and code-block rendering, file uploads, email notifications, and admin analytics.
- Designed a modular frontend and Express/MongoDB backend architecture.

**Why it stands out:** combines AI integration with real product capabilities such as moderation, user activity, analytics, and secure access control.

### 🎬 [CineSense](https://github.com/vignesh059/CineSense)
**Python · Flask · TensorFlow · Keras · SQLite · Docker**

A movie review sentiment analysis application that compares SimpleRNN and LSTM models through real-time predictions.

- Trained and evaluated two recurrent neural network architectures on the IMDB dataset.
- Benchmarked SimpleRNN at **82.90%** accuracy against LSTM at **86.92%**.
- Built a Flask dashboard with user authentication, movie context, review storage, and confidence scores.
- Containerized the application with Docker and prepared it for cloud deployment.

**Why it stands out:** clearly connects machine-learning experimentation, measurable model comparison, and production-style web delivery.

### 🧮 [Exam Portal](https://github.com/vignesh059/exam_portal)
**Node.js · Express.js · MongoDB · Docker · Jenkins · AWS EC2**

A role-based exam management system that collects student details and generates seating arrangements while avoiding same-branch adjacent seats.

- Implemented student and admin workflows with semester and branch filtering.
- Developed a seating algorithm for a four-column grid with adjacency constraints.
- Added Docker and Docker Compose support for repeatable environments.
- Connected the project to Jenkins CI/CD and AWS EC2 deployment workflows.

**Why it stands out:** demonstrates algorithmic problem solving combined with deployment automation and an operational backend.
